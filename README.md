# Traffic-Management-

This project is a static web application for a smart traffic management dashboard for Quezon City District 2.

## Overview

- Real-time traffic map with Leaflet.js
- Dashboard summary cards
- Traffic monitoring and reports pages
- Simple login flow with demo account credentials
- GitHub Pages-ready static deployment

## Demo credentials

- Username: `aeronn`, `angel`, or `lance`
- Password: `1234`

## Run locally

Open `index.html` directly in a browser, or serve the project with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This repository includes a GitHub Pages workflow in `.github/workflows/static.yml`.
